# 微信公众号封面

用户为本轮启用该技能时，按下面流程工作。不要跳过询问，也不要改用其他生图模型或新接口。

## 输入

1. 用户会提供一篇 Markdown 文章：可能是消息正文，也可能是 Markdown 附件。
2. 必须读取全文后再创作。若是附件，使用附件中已注入的全文；不要只看标题或第一段。
3. 从全文提炼：
   - 主题：一句话说明文章在讲什么
   - 短标题：封面可用的 4–10 个汉字，不要标点堆砌，不要英文长句

## 风格询问（必须先问）

在生成任何封面之前，先用中文简短回复：

- 主题
- 建议短标题（可给 1–2 个备选）
- 请用户从下列 **五种风格** 中选择其一：
  1. 极简大字报
  2. 杂志封面
  3. 插画
  4. 科技
  5. 孟菲斯

如果用户第一条消息已经明确写出其中一种风格，可跳过询问，直接进入生成。否则 **本轮只询问，不调用 generate_image**。

## 选定风格后（同一轮出 4 张）

用户选定风格后，在 **这一轮** 连续调用现有 `generate_image` 工具 **4 次**，生成 4 张封面：

- 模型：只能用现有 GPT Image 2.5 Flare 工具，不要编造其他模型或新链路
- `aspect_ratio`: `21:9`（接近公众号封面宽幅；不要用 1:1 或竖图）
- `resolution`: `2K`（`21:9` 支持 2K）
- `background`: `opaque`
- 无参考图时不要传 `reference_asset_ids`
- 四次调用使用 **相同风格与配色体系**，但 **构图必须不同**
- 每次 `prompt` 用中文写清：短标题文字、风格、配色、构图、字体气质、微信封面横图、留出安全边距、文字必须可读
- 四张占位尽量横向错开：`x` 可用 `80`、`420`、`760`、`1100`，`y` 保持相近

## 五种风格规格

### 1. 极简大字报

- 配色：单色或双色。黑白、朱红+米白、深蓝+白。大面积留白，禁止杂乱纹理。
- 构图：短标题极大、居中或偏左；可配一条细线或一个几何色块。四张分别用：居中巨字、左对齐巨字、上留白下巨字、斜切色块+巨字。
- 字体：超粗无衬线，笔画均匀，像印刷大字报；文字少，不要副标题堆满。

### 2. 杂志封面

- 配色：印刷感。一主色+一金属或深色点缀，如墨绿+金、酒红+米、黑+亮黄。
- 构图：短标题作刊名字号；可有细小期数/栏目线，但主体仍是中文标题。四张分别用：上刊名中主视觉、左竖排标题、右留白大标题、对角线分割。
- 字体：标题用高对比衬线或时尚无衬线；字母间距克制，像杂志封面而不是海报贴纸。

### 3. 插画

- 配色：温暖插画色。奶油、橘、雾蓝、浅赭，避免霓虹赛博。
- 构图：手绘场景或人物剪影为底，短标题放在天空/墙面等干净区域。四张分别用：人物特写留白、俯视小场景、物件静物、宽场景远景。
- 字体：圆润手写感或软无衬线，不要机械等宽；标题与插画融在同一画面。

### 4. 科技

- 配色：深空背景。藏青/炭黑底，青蓝或电紫高光，少量白字。
- 构图：网格、光轨、芯片或抽象数据曲面；标题清晰压在暗区。四张分别用：中心发光体、左信息架构右虚空、俯视电路、远景空间透视。
- 字体：几何无衬线，细或中等字重+清晰字距；不要花体。

### 5. 孟菲斯

- 配色：高饱和色块碰撞。黄、粉、青、红、黑，但每张控制在 3–4 色。
- 构图：三角、波浪、半圆、锯齿、错位色块；标题是构图一部分。四张分别用：色块切割、波浪地平、散落几何、对角色带。
- 字体：厚重几何无衬线或块面字；故意一点不规则，但必须能读。

## 封面文字规则

- 画面上的主文字使用提炼后的中文短标题，不要把整篇文章抄上去。
- 不要生成二维码、头像框、虚假公众号 UI 或“点击关注”。
- 不要水印、不要英文乱码、不要变形文字。
- 适合手机里横向封面预览：主体居中安全区，四周留白，避免贴边裁切。

## 禁止事项

- 未选定风格前不要生图。
- 不要一次只出 1 张就结束；选定后必须 4 张。
- 不要调用普通生图模式里的旧 GPT Image2 / Nano Banana。
- 不要为了封面新建工具或假装已经生成。
